# Catalog — no.fail site

This maps a pinned snapshot of the nofail-jidoka site subtree at commit
`86aa09a`. Load this catalog, pick the one door your question lives behind,
open that one card, and stop — never the whole cards folder, never the
territory. The inventory found no leftovers and no ghosts: every file here is
reached either by an edge or by a named contract, so this territory carries no
dead weight.

## Token / style sources

- **Global Stylesheet** (live) — every colour, typeface, and spacing step on
  the site resolves here → `cards/global-stylesheet.md`

## Layout spine

- **Base Layout** (live) — what wraps every page: head tags, site chrome, and
  the slot a page body lands in → `cards/base-layout.md`

## Components

- **Nav** (live) — where the top links come from and how the current page gets
  marked → `cards/nav.md`
- **Footer** (live) — the bottom link list, including the one route nothing
  else offers → `cards/footer.md`
- **Contact Form** (live) — what a visitor fills in, and what still works with
  JavaScript switched off → `cards/contact-form.md`
- **Rig Demo** (live) — the homepage widget that plays out three run
  scenarios, and why it depends on nothing → `cards/rig-demo.md`

## Content collections

## Site config
