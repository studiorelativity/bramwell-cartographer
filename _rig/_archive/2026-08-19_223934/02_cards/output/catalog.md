# Catalog — nofail-jidoka site, pinned at 16a4fc4

This maps the site subtree snapshot at commit `16a4fc4`: ten nouns, one card
each. Load this catalog, pick one door, open one card — never the whole cards
folder, never the territory.

Every file in the territory is either reached by an edge or covered by a
contract: the inventory found no dead weight, and that is a finding, not a gap.

## Token/style source

- **Global styles** (live) — if a colour, size, or spacing step is wrong anywhere on the site, this is where it is set → `cards/global-styles.md`

## Layout spine

- **Base layout** (live) — the wrapper every page is served inside; open this if something appears on all eleven pages → `cards/base-layout.md`

## Components

- **Nav** (live) — the top bar, where its six destinations are listed, and how the current page gets marked → `cards/nav.md`
- **Footer** (live) — the bottom bar, its seven destinations, and the year stamp → `cards/footer.md`
- **ContactForm** (live) — what a visitor types in, and what still happens when their browser has JavaScript off → `cards/contact-form.md`
- **RigDemo** (live) — the homepage widget that plays a pipeline run; open this if the demo misbehaves or reads wrong → `cards/rig-demo.md`

## Content collections

- **Content collections config** (live) — which frontmatter fields a writing, work, or people entry is allowed to have → `cards/content-config.md`

## Site config

- **Astro config** (live) — the site's public origin, whether it builds static, and which integrations are switched on → `cards/astro-config.md`
- **package.json** (live) — which command builds the site, and which Astro version it builds with → `cards/package-json.md`

## Serverless functions

- **Contact function** (live) — where a submitted form actually goes, what it rejects, and where the destination address is kept → `cards/contact-function.md`
