# Catalog — nofail-jidoka site snapshot

This maps the site subtree pinned at commit `dcba75e`: ten nouns, one card
each. Load this catalog, pick the one door your question lives behind, open
that one card — never the whole cards folder, and never the territory itself.

## Layout spine

- **Base layout** (live) — start here if a change you made shows up on every
  page, or should have and didn't → `cards/base-layout.md`

## Token and style

- **Global stylesheet** (live) — start here if you need a colour, a size, or a
  spacing step and are wondering whether you may type a number →
  `cards/global-stylesheet.md`

## Content collections

- **Content collections config** (live) — start here if a markdown file is
  refusing to build, or you want to add a field to one →
  `cards/content-collections-config.md`

## Components

- **Site nav** (live) — start here to add, rename, or reorder a destination in
  the top bar → `cards/site-nav.md`
- **Site footer** (live) — start here for anything below the fold on every
  page, including the year and the closing lines → `cards/site-footer.md`
- **Rig demo component** (live) — start here if the home page's interactive
  walkthrough behaves oddly, or you are wondering why it is so large →
  `cards/rig-demo.md`
- **Contact form component** (live) — start here for what a visitor types,
  sees, and gets told → `cards/contact-form.md`

## Serverless function

- **Contact serverless function** (leftover) — start here for what happens
  after a visitor presses send, and where the mail actually goes →
  `cards/contact-function.md`

## Site config

- **Astro config** (leftover) — start here for build-wide settings: the site
  origin, the output mode, the plugin list → `cards/astro-config.md`
- **Package manifest** (leftover) — start here for how the site is built and
  what it depends on → `cards/package-manifest.md`
